# biped_rl

## MLP Train

### 0. Prerequisites
Place the `<expert_data>.npz` generated by the `expert_data_collector` package from [biped_control_suite-v3](https://github.com/roger20415/biped_control_suite-v3.git) into the `bc/train_data/raw_data` directory.

### 1. Preprocess Data
```bash
cd bc
python preprocess_data.py
```
preprocess data config setup: `data/preprocess_data.py`

### 2. Train MLP
```bash
cd bc
python bc_train.py
```

> **Note:**
> * `bc_actor_body_weights.pth` and `bc_actor_head_weights.pth` will be generated in the `bc/model` directory.
> * `action_scales.npy` will be generated in the `bc/train_data` directory.
> * If you want to perform MLP Inference, these three files must be moved back to [biped_control_suite-v3](https://github.com/roger20415/biped_control_suite-v3.git).
